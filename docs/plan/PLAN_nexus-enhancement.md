## 2. 참조 문서에 없지만 필요한 기능 (프로젝트 자체 분석)

### 2.1 현재 백엔드에 있으나 프론트엔드 미연결

| 기능 | 백엔드 API | 프론트엔드 | 개선안 |
|------|-----------|-----------|--------|
| **벡터 유사도 검색** | `/api/search/similar/{id}` | 미연결 | Detail Panel에 "유사 노드" 섹션 추가 |
| **AI 요약** | `/api/analysis/summarize/{id}` | 미연결 | Detail Panel에 AI 요약 버튼 + 캐시 표시 |
| **인과 분석** | `/api/analysis/causal/{id}` | 미연결 | Detail Panel에 인과 분석 버튼 + 시각화 |
| **임베딩 생성** | `/api/ingest/embed` | IngestPage에만 | 자동화 연결 또는 노드 생성 시 자동 실행 |
| **Drip 스케줄러** | `/api/batch/drip/*` | IngestPage에만 | 대시보드 위젯으로 상태 표시 |

### 2.2 데이터 활용도 개선

| 현재 상태 | 개선안 |
|-----------|--------|
| 노드 생성 후 고립됨 (엣지 없음) | Autolinker 자동 실행 주기 단축 |
| 태그 데이터 미활용 | 태그 기반 필터 + 태그 클라우드 시각화 |
| source_type별 통계 없음 | 소스별 파이차트 + 트렌드 라인 |
| 시간 기반 분석 약함 | 주간/월간 성장 그래프 + 핫토픽 감지 |

## 4. 마일스톤 계획

### Phase 1: 사이드바 & Detail Panel 강화 (핵심 UI)

> 참조 문서의 가장 큰 GAP인 사이드바 3탭 구조와 Detail Panel 개선

#### 작업 목록
- [ ] 1.1 사이드바를 3탭 구조로 전환 (노드 / 뉴스 / 타임라인)
  - 노드 탭: 노드 목록 + 타입 필터 칩 + 사이드바 내 검색
  - 뉴스 탭: 최신 수집된 뉴스 카드 (카테고리 필터)
  - 타임라인 탭: 날짜별 노드 생성 이력
- [ ] 1.2 Detail Panel 슬라이드 강화
  - 우측 300px 슬라이드 패널
  - 노드 정보 (타입 뱃지, 제목, URL, 태그, 날짜)
  - 연결된 노드 목록 (관계 타입별 그룹핑)
  - AI 요약 버튼 → `/api/analysis/summarize` 연결
  - 인과 분석 버튼 → `/api/analysis/causal` 연결
  - 유사 노드 섹션 → `/api/search/similar` 연결
- [ ] 1.3 노드 편집/삭제 모달
  - 제목, 타입, 태그, 내용, URL 편집 폼

- [ ] 1.4 엣지 연결 모달
  - 대상 노드 검색 (실시간 autocomplete)
  - 관계 타입 선택 드롭다운
  - POST `/api/edges` 연결
- [ ] 1.5 Footer 통계 바
  - 노드 수, 엣지 수, 최근 업데이트 시간

### Phase 3: AI 강화 (자연어 쿼리 + GraphRAG)

> 그래프 데이터를 활용한 AI 대화형 인터페이스

#### 작업 목록
- [ ] 3.1 자연어 그래프 쿼리
  - 검색창에 자연어 입력 → AI가 의도 파악 → 그래프 필터링
  - 예: "반도체 관련 뉴스" → node_type=news + 반도체 관련 노드 하이라이트
  - 백엔드: POST `/api/ai/query` 엔드포인트
- [ ] 3.2 GraphRAG 채팅 패널
  - 우하단 또는 사이드바에 채팅 인터페이스
  - 질문 → 관련 노드/엣지 서브그래프 추출 → AI 답변 생성
  - 답변에서 참조된 노드 클릭 시 그래프에서 하이라이트
  - 백엔드: POST `/api/ai/chat` 엔드포인트
- [ ] 3.3 스마트 추천
  - Detail Panel에 "연관 노드 추천" 섹션
  - 임베딩 유사도 기반 + 그래프 구조 기반 하이브리드
- [ ] 3.4 지식 갭 탐지
  - 주기적 분석: 자주 언급되지만 노드가 없는 개념 탐지
  - 대시보드 또는 알림으로 "생성 추천" 제안

#### 예상 파일 변경
```
app/api/ai.py                                  — query, chat 엔드포인트 추가
```
